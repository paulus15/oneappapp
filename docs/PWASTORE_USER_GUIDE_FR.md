# Guide d’utilisation de PWA Store

## Qu’est-ce que PWA Store ?

PWA Store est un magasin d’applications Web. Vous y trouvez des applications présentées par des éditeurs vérifiés, examinées par notre équipe avant d’être publiées. Vous pouvez les ouvrir, les installer sur votre appareil, les garder en favoris et donner votre avis.

## Qu’est-ce qu’une PWA ?

Une PWA (Progressive Web App) est une application qui fonctionne dans votre navigateur, sans passer par un magasin d’applications classique. Beaucoup de PWA peuvent aussi être **installées** : elles ont alors leur icône sur votre écran d’accueil, s’ouvrent dans leur propre fenêtre et, pour certaines, fonctionnent sans connexion.

## Créer un compte

1. Choisissez **Créer un compte** et renseignez votre nom, votre e-mail, votre pays et un mot de passe.
2. Vous recevez un **code à 6 chiffres** par e-mail. Saisissez-le pour confirmer votre adresse. Le code est valable dix minutes.
3. Code non reçu ? Regardez dans vos courriers indésirables, puis utilisez « Renvoyer le code ».

Vous pouvez parcourir le Store sans compte. Un compte sert à ouvrir les applications depuis le Store, à garder vos favoris et votre bibliothèque, et à laisser des avis.

## Votre pays

Les applications proposées dépendent du pays : un éditeur peut réserver son application à certains pays.

- **Sans compte**, choisissez votre pays avec le bouton **Choisir mon pays** du Store. Ce choix reste dans votre navigateur ; il n’est jamais déduit de votre adresse IP. Sans choix, seules les applications disponibles dans tous les pays sont affichées.
- **Avec un compte**, c’est le pays de votre profil qui s’applique. Vous pouvez le changer dans « Mon espace » **une fois tous les 30 jours** ; chaque changement est enregistré.

Une application qui n’est pas proposée dans votre pays affiche « Cette application n’est pas disponible dans votre pays ».

## Sécurité du compte

Pour plus de sécurité, activez la **double authentification** dans « Mon espace » → « Sécurité du compte » : un code vous sera demandé par e-mail à chaque connexion.

## Ouvrir et installer une application

1. Ouvrez la fiche de l’application (consultable sans compte). Pour lancer l’application, connectez-vous : vous revenez ensuite sur la fiche.
2. Choisissez **Lancer l’application** ou **Ouvrir pour installer** : l’application s’ouvre dans un nouvel onglet.
3. Pour l’installer, utilisez la proposition de votre navigateur (bouton ou menu « Installer », « Ajouter à l’écran d’accueil »). Sur iPhone et iPad, utilisez le bouton Partager de Safari puis « Sur l’écran d’accueil ».

L’installation dépend de votre navigateur et de votre appareil : PWA Store ne peut pas l’imposer. Si vous avez installé l’application, vous pouvez choisir « Déclarer cette PWA installée » pour la retrouver dans votre bibliothèque.

## Les badges

| Badge                       | Signification                                                                                                                                                        |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Hébergée par PWA Store**  | Les fichiers de l’application ont été déposés sur PWA Store, analysés, approuvés, puis servis par PWA Store depuis une adresse qui lui est propre, séparée du Store. |
| **Hébergée par l’éditeur**  | L’application fonctionne sur le site de son éditeur. PWA Store a vérifié son adresse et sa fiche, mais son contenu peut évoluer sans nouvelle analyse.               |
| Catégorie, langues          | Le type d’application et les langues dans lesquelles elle est disponible.                                                                                            |
| Âge (3+, 7+, 12+, 16+, 18+) | Âge minimum calculé par PWA Store à partir des réponses de l’éditeur sur le contenu. Ce n’est pas une classification officielle (IARC, PEGI, ESRB).                  |
| **Contient des annonces**   | L’éditeur a déclaré que son application affiche des annonces, y compris de réseaux publicitaires tiers.                                                              |

Survolez ou touchez un badge d’hébergement pour lire son explication.

## Favoris

Sur la fiche d’une application, choisissez **Ajouter aux favoris** (icône en forme de cœur). Retrouvez vos favoris dans « Mon espace ». Touchez de nouveau le bouton pour retirer l’application.

Dans « Mon espace » → « Préférences », l’option **Mémoriser les applications que je consulte** affiche vos fiches récemment consultées. Elle est facultative ; la désactiver efface cet historique.

## Avis

- Pour noter une application, il faut un compte avec une adresse e-mail confirmée.
- Un seul avis par application (2000 caractères au plus). Vous pouvez le modifier ou le supprimer depuis « Mon espace » → « Mes avis ».
- L’éditeur peut vous répondre. Les avis contraires aux règles peuvent être masqués par l’équipe.

## Signaler un problème

Sur la fiche d’une application, ou sous un avis, choisissez **Signaler**, puis le motif (contenu dangereux, arnaque, atteinte à la vie privée, application cassée, usurpation…). Notre équipe examine chaque signalement. Vous suivez leur issue dans « Mon espace ».

## Nous contacter

Utilisez la page **Contact** (lien en bas de chaque page) : indiquez votre nom, votre e-mail, le sujet et votre message. La page **Aide** répond aux questions fréquentes.

## Choisir la langue

Le sélecteur de langue (**FR / EN**) se trouve dans la barre de navigation. Votre choix est mémorisé sur cet appareil et, si vous êtes connecté, sur votre compte. La traduction anglaise des messages du serveur et des e-mails est **en cours** : certains restent pour l’instant en français.

## Supprimer son compte

Dans « Mon espace » → « Sécurité du compte », choisissez **Désactiver mon compte** et confirmez avec votre mot de passe et le code reçu par e-mail. Votre compte est désactivé aussitôt ; vos données personnelles sont **anonymisées 30 jours plus tard**. Vos avis restent visibles, mais anonymes.

Avant cela, vous pouvez télécharger vos données depuis « Mon espace » → « Mes données » (**Exporter mes données**). La [politique de confidentialité](/privacy) liste les données collectées et leurs durées de conservation.
